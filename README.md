# Cybersecurity
This repository is a personal collection of small projects, scripts, and notes created along my cybersecurity learning journey. It's a space where I experiment, practice new concepts, and document what I learn as I go — from basic security tools to hands-on exercises and write-ups.
## Projects
- Network Communication Model: Simulates TCP/IP-style packet encapsulation across network layers (Application, Transport, Internet, Network Access), each adding its own header via a shared interface.
- TCP Server Model:
  - Basic: A simple Python TCP client-server implementation built to better understand socket programming and the fundamentals of the TCP protocol.
  - Advanced: An enhanced Python TCP client-server application featuring password authentication and an interactive dictionary lookup service over sockets.
- Log analyzer: Detects brute-force SSH login attempts by analyzing failed authentication timestamps per IP with sliding-window.
